### Folder structure
Below is folder structure
```bash
Kaul_Kartikay/
├── Assignments/
├── CWandHW/
└── Notes/
```

### Folder description
`Kaul_Kartikay` is the root folder
### Assignments
It contains all the notebooks that solves the problems given in pdf files in training

### CWandHW
contains notebooks or python scripts that contain Classwork along with Homework

### Notes
contains `odt` files that have briefly written class notes to keep track of what was done and home assignment tasks.
